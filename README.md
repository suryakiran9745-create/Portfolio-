# Leo Das — Portfolio

A responsive, single-page portfolio starter built with plain HTML, CSS and JavaScript. It can be deployed directly to Vercel as a static site.

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com`, `YOUR_GITHUB`, and `YOUR_LINKEDIN`.
3. Review the About, project and skills copy. Remove anything that does not accurately describe you.
4. Add project repository links and real screenshots if available.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder (the `index.html`, `styles.css`, and `script.js` files must be at the repository root).
2. Sign in at https://vercel.com and choose **Add New → Project**.
3. Import the GitHub repository.
4. Framework Preset: **Other**. Build Command: leave blank. Output Directory: `.`.
5. Select **Deploy**. Vercel will provide a public `*.vercel.app` URL.
6. For future edits, push changes to the connected GitHub repository; Vercel redeploys automatically.

No build command or environment variables are required.
